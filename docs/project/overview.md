# ИИ-помощник по учебным материалам

Сервис помогает студенту разбираться в загруженных учебных материалах. Пользователь добавляет документ, задаёт вопрос или просит краткий пересказ. Помощник формирует ответ на основе содержимого документа и указывает источник — например, название файла и страницу.

**Основной пользователь:** студент.

**Основные функции:**

- загрузка учебного материала;
- ответы на вопросы по загруженному материалу с указанием источника;
- создание краткого пересказа;
- генерация вопросов для самопроверки.

Помощник работает только с материалами, которые загрузил пользователь. Если нужной информации в них нет, он сообщает об этом, а не пытается выдать ответ как факт.

## Комплект документации

1. **Описание проекта** — для команды и преподавателя; объясняет назначение сервиса и его функции.
2. **Требования** — для разработчиков и тестировщиков; описывает поведение системы и критерии проверки.
3. **Архитектура системы** — для разработчиков; показывает основные компоненты и их взаимодействие.
4. **Документация API** — для разработчиков; описывает способы передачи документов и запросов между частями системы.
5. **Документация ИИ-компонента** — для разработчиков; объясняет, как помощник обрабатывает материалы и формирует ответы.
6. **Руководство пользователя** — для студентов; объясняет, как загрузить материал и пользоваться функциями сервиса.
