# Требования

## User Stories

### US-01. Ответ на вопрос по материалу

Как студент,
я хочу задать вопрос по загруженному учебному материалу,
чтобы быстрее найти нужную информацию.

Критерии приёмки:

- система принимает вопрос и использует загруженный материал для поиска ответа;
- ответ содержит ссылку на документ и страницу, где найдена информация;
- если ответа в материале нет, система сообщает об этом.

### US-02. Краткий пересказ

Как студент,
я хочу получить краткий пересказ учебного материала,
чтобы быстро вспомнить его основные идеи.

Критерии приёмки:

- система формирует пересказ по выбранному документу;
- пересказ содержит основные идеи материала;
- система сообщает, если документ не удалось обработать.

### US-03. Вопросы для самопроверки

Как студент,
я хочу получить вопросы по учебному материалу,
чтобы проверить, насколько хорошо я его понял.

Критерии приёмки:

- система формирует вопросы по выбранному документу;
- вопросы относятся к содержанию материала;
- если документ не удалось обработать, система показывает сообщение об ошибке.

## Use Case

### UC-01. Ответ на вопрос по учебному материалу

**Актор:** студент

**Цель:** получить ответ на вопрос с опорой на загруженный материал.

**Предусловие:** студент загрузил учебный документ.

**Основной сценарий:**

1. Студент открывает загруженный документ.
2. Вводит вопрос и отправляет его.
3. Система ищет подходящую информацию в документе.
4. ИИ-компонент формирует ответ на основе найденных фрагментов.
5. Система показывает ответ и указывает документ и страницу-источник.

**Альтернативный сценарий:**

Если в документе не нашлось ответа, система сообщает, что информации недостаточно.

**Результат:** студент получает ответ с источником или сообщение, что материал не содержит нужной информации.
