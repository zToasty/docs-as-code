# Data Sheet

## Общая информация

**Название датасета:** SberQuAD (Sber Question Answering Dataset).

**Источник:** https://huggingface.co/datasets/kuznetsoffandrey/sberquad

**Назначение:** обучение и оценка систем, отвечающих на вопросы по русскоязычному тексту.

**Язык:** русский.

**Лицензия:** в рассмотренной карточке Hugging Face обозначена как unknown; условия использования требуют уточнения.

**Связь с выбранной моделью:** точный состав обучающих данных Qwen2.5-7B-Instruct не раскрыт. Подтверждений использования SberQuAD при её обучении в рассмотренных источниках нет. Для нашего проекта датасет выбран для потенциальной оценки качества.

## Состав данных

**Объём опубликованной версии:**

| Выборка | Количество записей |
|---|---:|
| train | 45 328 |
| validation | 5 036 |
| test | 23 936 |
| Всего | 74 300 |

**Тип данных:** текстовые фрагменты, вопросы и разметка ответов.

**Основные поля:**

- `id` — идентификатор записи;
- `title` — заголовок;
- `context` — исходный текст;
- `question` — вопрос по тексту;
- `answers.text` — список эталонных ответов;
- `answers.answer_start` — позиции начала ответов в исходном тексте.

## Получение данных

Датасет создан на основе фрагментов русскоязычной Википедии. Вопросы составлялись участниками краудсорсинговой разметки, а ответы отмечались как фрагменты исходного текста.

SberQuAD был представлен в рамках Sberbank Data Science Journey 2017. Подробное описание и анализ опубликованы в статье авторов.

## Предобработка

Полная последовательность очистки и нормализации исходных данных в рассмотренной карточке Hugging Face не указана.

В рамках нашей практической работы скачивание и предобработка датасета не выполнялись.

Для будущей оценки планируется:

- проверить заполненность контекста, вопроса и эталонного ответа;
- проверить соответствие `answer_start` тексту ответа;
- сохранять исходный контекст без изменений, нарушающих позиции разметки;
- передавать модели контекст и вопрос, оставляя эталонный ответ только для оценки.

## Ограничения

Следующие ограничения определены на основе структуры датасета и предполагаемого применения в нашем проекте:

1. Фрагменты Википедии отличаются от реальных лекций и конспектов. Результаты на SberQuAD могут не отражать качество на учебных документах.

2. Эталонные ответы представлены фрагментами текста. Развёрнутый правильный ответ модели может отличаться от эталона по формулировке.

3. Датасет не позволяет полноценно проверить обработку PDF: извлечение текста, распознавание формул, таблиц и определение номера страницы.

4. Для оценки отказов при отсутствии информации потребуется отдельно проверить наличие подходящих примеров и при необходимости подготовить дополнительную выборку.

5. Возможное пересечение с обучающими данными Qwen неизвестно. Поэтому результат нельзя считать гарантированной оценкой качества на ранее неизвестных модели материалах.

## Использование в проекте

SberQuAD планируется использовать для предварительной оценки ответов ИИ-помощника по учебным материалам.

Модель получит `context` и `question`. Полученный ответ будет сравниваться с эталонным ответом и проверяться на подтверждённость исходным текстом.

Для коротких ответов можно рассчитывать Exact Match и token-level F1. Развёрнутые ответы дополнительно потребуют проверки по смыслу.

Эта оценка проверяет ответы по предоставленному контексту. Для проверки всей системы, включая поиск фрагментов и поля `sourcePage` и `sourceExcerpt`, потребуется отдельная выборка учебных документов с разметкой источников.

Обучение и оценка модели на SberQuAD в рамках текущей практической работы не проводились.
