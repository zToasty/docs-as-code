# Model Card

## Общая информация

**Название модели:** Qwen2.5-7B-Instruct.

**Источник:** https://huggingface.co/Qwen/Qwen2.5-7B-Instruct

**Автор / организация:** Qwen Team, Alibaba Cloud.

**Задача модели:** генерация текста и ответы на запросы пользователя с учётом инструкций и переданного контекста.

**Язык:** многоязычная модель; авторы заявляют поддержку более 29 языков, включая русский и английский.

**Количество параметров:** 7,61 млрд.

**Лицензия:** Apache 2.0.

**Статус в проекте:** модель выбрана для предполагаемого использования. В рамках практической работы запуск, дообучение и собственная оценка качества не проводились.

## Использование в проекте

Модель планируется использовать в проекте «ИИ-помощник по учебным материалам» для формирования ответов на вопросы по загруженным документам.

Пользователь загружает PDF- или TXT-файл через `POST /documents`. Система извлекает текст, разбивает его на фрагменты и сохраняет сведения об источнике. Статус обработки доступен через `GET /documents/{documentId}`.

При обращении к `POST /documents/{documentId}/questions` система находит фрагменты документа, связанные с вопросом, и передаёт их модели вместе с вопросом и инструкцией отвечать на основе материала.

Модель формирует текст ответа для поля `answer`. Поля `sourcePage` и `sourceExcerpt` система заполняет на основе сохранённых метаданных и текста выбранного фрагмента. Соответствие ответа указанному источнику необходимо проверять отдельно.

## Входные данные

Модель получает текстовый запрос, содержащий:

- инструкцию отвечать на основе переданных материалов;
- вопрос пользователя;
- найденные фрагменты учебного документа.

Исходный PDF-файл непосредственно в языковую модель не передаётся: предварительно система извлекает из него текст.

## Выходные данные

Модель возвращает текстовый ответ на вопрос пользователя.

Система включает ответ в JSON-структуру API вместе с номером страницы и цитатой источника. Наличие ссылки на источник само по себе не гарантирует правильность ответа.

## Данные для обучения

Авторы сообщают, что для предварительного обучения семейства Qwen2.5 использовался корпус объёмом до 18 трлн токенов.

Полный перечень конкретных наборов данных для обучения выбранной модели в рассмотренной документации не раскрыт. Загруженные пользователями учебные документы используются как контекст запроса, а не как данные для дообучения.

## Метрики качества

В разделе Evaluation & Performance на странице модели приведена ссылка на публикацию авторов с результатами оценки семейства Qwen2.5.

Численные значения метрик непосредственно на странице выбранной модели не приведены. Результаты других размеров модели нельзя автоматически переносить на Qwen2.5-7B-Instruct.

Для нашего проекта планируется оценивать:

- правильность ответа относительно учебного материала;
- подтверждённость ответа указанной цитатой;
- корректность отказа при отсутствии информации в документе.

Собственные значения этих показателей пока не получены.

## Ограничения

### Ограничение из документации модели

1. Длина входного контекста ограничена. В стандартной конфигурации предусмотрено 32 768 токенов; обработка более длинного контекста требует дополнительной настройки. Поэтому большие документы необходимо разбивать на фрагменты.

### Потенциальные ограничения для нашего проекта

Следующие ограничения являются анализом предполагаемого применения и требуют проверки:

2. Модель может сформировать правдоподобный ответ, который не подтверждается документом. Необходима проверка ответа по исходному материалу.

3. Ошибки извлечения текста из PDF, особенно в таблицах и формулах, могут приводить к неправильным ответам.

4. Если система поиска не передаст нужный фрагмент, модель может не получить информацию, необходимую для ответа.

5. Качество на русскоязычных учебных материалах и специальной терминологии необходимо оценить отдельно: поддержка русского языка не гарантирует одинаковую точность во всех дисциплинах.

## Не рекомендуется использовать

В рамках проекта не рекомендуется использовать модель:

- как единственный источник при принятии медицинских, юридических или других ответственных решений;
- для автоматического выставления оценок без проверки преподавателем;
- для получения гарантированно достоверных ответов без обращения к первоисточнику.

Эти рекомендации определены для нашего проекта и не являются цитатой ограничений авторов модели.
