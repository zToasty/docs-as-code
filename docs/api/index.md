# API

API предоставляет доступ к функциям ИИ-помощника по учебным материалам.

## Основные операции

- `POST /documents` — загрузить учебный документ;
- `GET /documents/{documentId}` — получить статус обработки документа;
- `POST /documents/{documentId}/questions` — задать вопрос по документу и получить ответ с источником.

## Спецификация

Полное описание API находится в файле [openapi.yaml](openapi.yaml).
